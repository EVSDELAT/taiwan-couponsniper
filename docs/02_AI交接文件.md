# AI 交接文件

## 目前版本

V1.04

## 本次完成內容

- GitHub Actions 每三小時抓取 Uber Eats 與 foodpanda 公開優惠資料。
- 將整理後的快取寫入 docs/coupons.json，GitHub Pages 只讀取站內快取。
- 抓取失敗時保留上一份成功資料；兩個來源都失敗才讓工作流程失敗。
- 新增 GitHub Pages 與 ChatGPT Site 的資料流、協定、限制及風險說明。
- GitHub Pages 靜態頁面顯示版本 V1.04 與快取更新時間。
- 製作者名稱、聯絡我及回報問題已整合至頁首右側；原大型製作者區塊不再佔用版面。
- 平台切換區新增「選擇優惠券的平台」標題。
- 排程正規化支援來源把優惠碼嵌入 `col_0` 的格式，避免所有優惠被誤判為平台資訊。
- 靜態頁面已帶入 `identityMatches()`，可正常切換新用戶、舊用戶與全部用戶。

## 驗證結果

- node --check scripts/fetch-coupons.mjs
- node --check scripts/build-pages.mjs
- node scripts/fetch-coupons.mjs：成功取得 Uber Eats 77 筆、foodpanda 39 筆（數量會隨來源變動）。
- node scripts/build-pages.mjs：成功產生 docs/index.html。
- 靜態頁面的優惠資料請求為 ./coupons.json，不再呼叫 /api/coupons。

## 未完成與限制

- GitHub Actions 的 cron 可能延遲，不能視為整點保證。
- 優惠券來源為外部公開資料，內容及有效期必須以外送平台結帳頁為準。
- GitHub Pages 的自動定位仍由瀏覽器授權位置，並使用 OpenStreetMap Nominatim 反查。

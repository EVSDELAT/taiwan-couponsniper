# 技術選型與開發環境

- 前端：單一 HTML、CSS、原生 JavaScript，避免引入大型框架。
- ChatGPT Site：worker/index.js 的 ESM Worker 入口，提供 HTML 與 /api/*。
- GitHub Pages：docs/index.html 與 docs/coupons.json，完全由瀏覽器執行。
- 排程：GitHub Actions，使用 Node.js 內建 fetch 下載 JSON。
- 建置：Node.js ESM；scripts/build-pages.mjs 從 Worker 頁面產生靜態入口。
- 測試：node --check、快取資料結構檢查及部署後 HTTP 驗證。

所有外部連線均使用 HTTPS。優惠資料是公開 JSON，不在前端或儲存庫放置秘密金鑰。

# 版本修改紀錄

## V1.01（2026-09-16）

- 項目：GitHub Pages 改為 Actions 排程快取優惠券。
- 原因：原本由每位瀏覽器訪客直接呼叫第三方 JSON，容易受到 CORS、來源限流及暫時故障影響。
- 影響：Pages 使用 docs/coupons.json；資料約每三小時更新一次；ChatGPT Site Worker API 維持原有即時流程。
- 主要檔案：.github/workflows/pages.yml、scripts/fetch-coupons.mjs、scripts/build-pages.mjs、docs/index.html、docs/coupons.json、docs/05_系統架構說明.md。
- 驗證：Node 語法檢查、兩來源下載、77 筆 Uber Eats 與 39 筆 foodpanda 正規化、靜態頁面不再含 /api/coupons。
- 已知限制：GitHub cron 可能延遲；外部優惠資料及 Nominatim 服務的可用性不由本專案保證。

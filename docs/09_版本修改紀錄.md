# 版本修改紀錄

## V1.06（2026-10-06）

- 原因：來源改用「複製優惠碼」文字且混入香港資料，舊解析造成台灣優惠隱藏。
- 修正：支援新舊複製文字、拆開同列多組代碼；排除香港、澳門與港幣資料，備援快取也先過濾。
- 檢查：若正規化後全部沒有代碼或領取入口，拒絕覆蓋正常資料。
- 主要檔案：scripts/fetch-coupons.mjs、scripts/build-pages.mjs、docs/coupons.json、docs/index.html。
- 驗證：語法與建置檢查、最新來源解析、香港資料零筆及多代碼回歸測試。
- 限制：第三方來源無法保證平台兌換成功；ChatGPT Site 尚未重新部署。

## V1.05（2026-09-16）

- 項目：將頁首右上方的製作人資訊與更新日期合併為單一上下堆疊資訊卡。
- 原因：避免兩張卡片並排佔用頂端空間，讓重點集中於優惠查詢內容。
- 影響：第一列固定顯示「製作人：EVS-ZHAO TECH©」及「聯絡我」「回報問題」按鈕，第二列顯示 V1.05 與更新日期；桌面維持緊湊高度，手機於極窄寬度允許按鈕換行並限制寬度。
- 主要檔案：worker/index.js、scripts/build-pages.mjs、docs/index.html、docs/02_AI交接文件.md、docs/03_專案目前狀態.md。
- 驗證：`node --check worker/index.js`、`node --check scripts/build-pages.mjs`、`node scripts/build-pages.mjs`，並檢查產物含 `headerInfo`、V1.05、製作人文字及兩個聯絡按鈕。
- 已知限制：極窄螢幕可能將第一列按鈕換至下一行；更新日期仍由優惠資料來源提供，來源未提供時顯示「來源未提供」。

## V1.01（2026-09-16）

- 項目：GitHub Pages 改為 Actions 排程快取優惠券。
- 原因：原本由每位瀏覽器訪客直接呼叫第三方 JSON，容易受到 CORS、來源限流及暫時故障影響。
- 影響：Pages 使用 docs/coupons.json；資料約每三小時更新一次；ChatGPT Site Worker API 維持原有即時流程。
- 主要檔案：.github/workflows/pages.yml、scripts/fetch-coupons.mjs、scripts/build-pages.mjs、docs/index.html、docs/coupons.json、docs/05_系統架構說明.md。
- 驗證：Node 語法檢查、兩來源下載、77 筆 Uber Eats 與 39 筆 foodpanda 正規化、靜態頁面不再含 /api/coupons。
- 已知限制：GitHub cron 可能延遲；外部優惠資料及 Nominatim 服務的可用性不由本專案保證。
